## 🟧 Fase 3: Controle de Frequência e Alertas de Faltas

### ✅ Tarefa 3.1 — Criação das Tabelas de Encontros e Presenças no Supabase
- **Comandos SQL:**
  ```sql
  CREATE TABLE encontros (
      id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
      data_encontro DATE NOT NULL UNIQUE,
      tema TEXT,
      observacao TEXT,
      created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
  );

  CREATE TABLE presencas (
      id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
      encontro_id BIGINT REFERENCES encontros(id) ON DELETE CASCADE,
      crismando_id BIGINT REFERENCES crismandos(id) ON DELETE CASCADE,
      status TEXT NOT NULL CHECK (status IN ('PRESENTE', 'FALTA', 'JUSTIFICADO')),
      observacao TEXT,
      created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
      UNIQUE(encontro_id, crismando_id)
  );
  ```
